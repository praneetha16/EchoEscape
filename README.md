# EchoEscape 🎵

Escape through music.

A music-based puzzle escape room web application where players solve audio and lyric challenges to progress through mysterious rooms.

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- FastAPI
- MySQL

## Features

- Reverse audio puzzles
- Emoji song guessing
- Instrument sequence memory
- Jumbled lyrics
- Complete the lyrics
- Singer/title guessing
